[[wiki-synchronisation]]
== Wiki synchronisation

One-way push, repo → wiki, on every merge to `main` that touches this
directory:

* Publisher: `.machine_readable/scripts/forge/wiki-sync.sh`
  (`just wiki-sync` to run by hand, `just wiki-sync-dry-run` to preview).
* Automation: `.github/workflows/wiki-sync.yml`.
* Transformations applied at publish time: `README.adoc` is published as
  `Home.adoc` (Gollum's landing page), machine-only `*-AI-MANIFEST.a2ml`
  files are skipped, and `link:Page.adoc[` crosslinks are rewritten to the
  extension-less form that resolves between wiki pages.
* Credential: the `WIKI_SYNC_PAT` repository secret (a PAT with
  `contents:write` here). The built-in `GITHUB_TOKEN` cannot push to the wiki
  git — a GitHub limitation. Without the secret the workflow skips cleanly.

AsciiDoc renders natively in GitHub wikis, so pages are pushed as-is apart
from the transforms above.
